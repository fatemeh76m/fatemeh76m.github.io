# Fatemeh Maddahzadeh — Portfolio

A responsive portfolio website in English and Italian, made with plain HTML, CSS and JavaScript. No build step or package installation is required.

Open `index.html` to preview locally. The CV PDFs sit beside the page so their relative links also work on GitHub Pages.

The portfolio project description reflects the documented implementation scope and uses synthetic invoice data. The master’s degree is listed as expected, consistent with the CV.
